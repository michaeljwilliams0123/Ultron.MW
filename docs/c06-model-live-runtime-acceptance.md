## One bounded, real canary

Owner-authenticated `POST /api/brain/c06-live-canary` accepts exactly:
```json
{"action":"evaluate","key":"c06-live-20261104-01","expectedStopVersion":1}
```
The user selects the action in Mission Control. The backend enforces owner identity, unpaused, exact durable stop version, owner profile $0 paid-spend, and a cap of 12 new receipts/hour. It reads independent **live GitHub REST** metadata for generation workflow run [#41775191071](https://github.com/michaeljwilliams0123/Ultron.MW/actions/runs/41775191071). Its run ID, attempt, actor, repository, main branch, workflow path, outcome, source SHA and archived artifact ID/name/size/GitHub-provided SHA-256 digest must equal their immutable origin.

Only after those readbacks agree does it call the *model-generated* classifier through the separately reviewed safe adapter and insert `c06_live_receipts` into PostgreSQL. The insert is fenced against a stop change in the same statement, uses a unique idempotency key and has an independent SELECT readback; uncertain write results are not retried blindly. Existing keys return the same row and cannot create a second effect. A bounded Hatchable realtime notification follows a confirmed commit. `GET /api/brain/c06-live-canary` reports the latest eight owner-only receipts without tokens or private code.

The GitHub artifact digest is GitHub API **metadata**, not a locally downloaded and cryptographically hashed artifact ZIP. There is no external write, no billed inference and no model-granted administrative permission. The persisted evaluation receipt alone is **not full #245 production release acceptance** and never sets `productionAccepted=true`. This does, however, prove real source-matched Hatchable code execution and durable observable runtime effects if the live owner/stop/negative tests pass.
