2. Set up GitHub Face ID sign-in

GitHub passkeys belong to your GitHub account, separately from Hatchable login and Ultron's operation-approval credential.

Open GitHub security settings GitHub passkey guide

In GitHub: Settings → Password and authentication → Passkeys → Add a passkey. Confirm with Face ID and keep your recovery method available.

3. Check your Ultron owner passkey

The existing Ultron passkey is a separate credential. A previous enrollment is recorded, but this page cannot tell whether it is available on this iPhone. Do not create a duplicate credential unless you are following the required enrollment authorization.

Open Ultron passkey page

New Ultron passkey enrollment may require an already authorized owner-signed grant; logging into Hatchable does not replace it.
