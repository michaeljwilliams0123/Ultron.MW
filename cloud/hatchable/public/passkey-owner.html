One-time owner-signed enrollment, then a device passkey authorizes exact GitLab branch operations. Everything executes in Hatchable cloud. Your passkey private key stays inside your authenticator. The existing owner-signing private key must never be uploaded here.

1. Register your passkey

Initial enrollment requires an existing owner-signed P-256 grant. This establishes that the new credential belongs to the owner rather than merely someone with an authenticated browser session.

Sign this request with your existing owner-controlled key using node scripts/owner-grant.mjs sign PRIVATE_JWK REQUEST_JSON on a trusted device. Paste only the resulting JSON envelope—not the private key—below. This bootstrap step is needed only for registering a new device.
